# PLC直连接入说明

本轮D201、D203～D206、M50与历史业务的设计见[新版统一方案](unified-plc-business-and-data-plan.md)。下面“当前代码”描述既有实现，不表示已适配新点位。

设备唯一标识是`cleaning.plc.devices[].id`，通过采集、消息、业务、HTTP和数据库统一使用。IP、端口、unitId是连接参数。用户操作经过登录账号和权限检查。

点位取舍、五态和历史保存的业务方案见[点位与历史方案](plc-data-and-history-plan.md)。本轮只整理方案，没有将方案中的历史数据模型或流程写入程序。

先核对[禁用模板](../src/main/resources/plc-points.example.yml)的协议地址、功能码、数据类型、字节序、倍率、偏移、无效码、极性、单位和业务编号，再显式加载外部配置。主开关、设备开关和写入开关默认关闭，现场标签数字不是默认协议地址。

## 当前代码的业务映射

| field | 槽位 | 数据含义 |
|---|---|---|
| manualMode / running | 1 | 检修模式、自动运行事实 |
| emergency / fault / faultCode | 1 | 急停状态、系统故障和原始故障码 |
| up / down | 1 | 整体运动方向 |
| ropeTension | 1～8 | 索拉力，业务单位kg，关联ropeId/sensorId/winchId |
| winchHeight / winchSpeed | 1～4 | 各绞机高度m、速度m/min |
| winchTorque | 1～4 | 当前期望输入已换算的kg量 |
| winchRunning / winchFault / encoderFault | 1～4 | 可选本机事实 |
| ringHeight / groupSpeed | 1 | 独立圆环高度、整组速度 |

两索均有效才给该机平均拉力；整组均值附有效通道数量。圆环高度不由四机均高替代，同步速度不复制成各机实测速度，缺测不补零。现有单机方向仍沿用整体方向，不能当作独立方向已实现。

新提供点位表明确D40～D47已经是kg，旧模板的raw-unit=N需要在后续实施时纠正，不能重复从N/kN换算。D70～D73原值的等效力换算公式已写入方案，运行代码尚未接入该换算。

## 当前链路与边界

PlcDataIngress登记独立PLC I/O和分发工作者，主动取缓冲调用表示层；底层驱动、缓冲和DAO不调用业务服务。HTTP线程只登记并非阻塞入队，不等待PLC网络响应。

当前每设备最新快照允许合并覆盖，因此不能用于无损保存每帧历史。首页SSE由上层推送任务读取清洗服务快照，不直接读取PLC或修改系统状态。

目标轮询间隔500ms不等于严格固定采样；多寄存器块顺序读取，不保证PLC内部原子冻结。短脉冲可能漏采，不能按速度/时间或单程计数补算完整清洗。

命令同requestId同内容幂等，每设备一个在途参数修改，急停优先但队列满仍可拒绝。断线读取退避，写入超时或部分成功不自动重发或回滚。急停写响应仅表示请求写入，实际停止仍需上行事实确认。

已有历史批次DAO保存实现，任务默认关闭；实时采集到每次清洗记录、完整曲线和可靠归档仍未接通。参数实际读回、生效确认和版本保存仍未闭环。远程启动、复位、解除急停、暂停/恢复均未开放。
